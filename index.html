Alt Text Checker

Paste HTML, JSX or JSON (page builder data) code, hit Check, and see images with no alt, an empty alt, or a useless alt like “photo”. Everything runs in your browser; nothing is uploaded.

Missing alt means the image has no alt attribute at all. That is an error and should be fixed.

Empty alt means alt="". That is correct for a purely decorative image, but an image that carries meaning needs a description.

JSON fields like "alt_text", "image_alt_text" or "background_image_alt" are checked too. If the alt is empty but the image fields next to it (mobile, desktop, src, url) have a picture, it counts as a problem. If those are empty too, it is listed as an empty slot.

Useless alt means it holds a word like photo or image, or a file name. Describe what is in the picture instead.
